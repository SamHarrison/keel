# Scenario walkthrough — elicitation by narration (~20 min each)
Pick one: normal day / degraded day (a dependency is down) / adverse day
(someone hostile). Narrate minute-by-minute; at each beat ask "what must be
true here?" — every answer is a candidate BRD or PRD row. Record gaps found.
Output: scenarios/S_<alias>.md (mint first; actor = a stakeholder row,
mode per day-type) + gap notes into the register.
