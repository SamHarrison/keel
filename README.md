## How this repo works (keel)

This project runs **keel** — a requirements-first process for agentic
development, tailored from ISO/IEC/IEEE 29148. The short version:

- **Truth is layered and addressable.** vision → profiles(+BRDs) →
  scenarios → PRD (the spec), joined by `docs/trace/links.yaml`; decisions
  are ADRs in `docs/decisions/`. Every statement has a permanent identity
  (uid `15NM7` ≡ alias `word.word`); references pin versions and stale
  pins fail the build.
- **Authored vs derived.** `docs/` is written by people/agents; `build/`
  is regenerated by `tools/req` and never edited; `ledger/` is
  machine-written memory, audited against the diff.
- **Three gate rings, one verdict.** Pre-commit hook, optional no-mistakes
  push gate, and CI all run the same checks.

Document flowdown: README (you are here) → `CLAUDE.md` (agent contract) →
`docs/process.md` (**normative**) → `docs/keel-reference.md` (the complete
explanation of every file, schema, and command). On any conflict the
process doc wins.
